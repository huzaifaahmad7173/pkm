# Model Selection

## Overview

Model selection is the process of choosing the AI model that best fits a specific feature.

The best model is not always the largest or newest model.

---

# Selection Criteria

Consider:

- Quality
- Accuracy
- Cost
- Response speed
- Context size
- Privacy
- Reliability

# Best Practices

- Test models using the project's evaluation set.
- Compare quality and cost.
- Document why a model was selected.
- Avoid changing models without testing.
- Keep track of models currently in use.
